# Data

- `species.json`: one entry per National Dex number 1–649: `[english, german, type1, type2, family, catch rate]`. Types index into `Type` (`-1` = none). Catch rates are those of the unmodified generation 5 games, from [PokéAPI](https://github.com/PokeAPI/pokeapi).
- `locations.json`: Black 2 / White 2 met-location names by index: `[english, german]`. Taken from [PKHeX](https://github.com/kwsch/PKHeX) (GPL-3.0).
